# M1 Title-Scene Oracle

## Purpose

Prove the first native C route against the owner ROM before broadening the
translation. `nnes` supplies the local reference run; it is not linked into the
native product.

## Dependencies

Requires the native title-scene runtime and an admitted local ROM input.

## Acceptance

Fixed title-route inputs compare at named frame checkpoints for the translated
state, relevant RAM, command stream, and title transition. Any difference has
a frame number, source-address scope, and disposition.
