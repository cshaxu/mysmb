## Current Technical Baseline

The product uses one shared native C90 game implementation for DOS16 and Win32 x86/x64. Host adapters provide input, timing and presentation only. S4 closed at 1,870/1,992 with six bounded original-ROM routes at zero x86/x64 difference. DOS16 remains an active OpenNT-toolchain target.
