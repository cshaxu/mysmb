# Project Goals

1. Produce a readable, complete C translation of reviewed SMB1 program logic, preserving original state and control-flow semantics.
2. Make translation claims traceable to reviewed source addresses and verified against an owner-supplied ROM without committing protected material.
3. Build the same portable game logic first for a 25 MHz 486SX running real-mode MS-DOS, then for native 32-bit and 64-bit hosts.
4. Provide original-style graphical presentation and a distinct object-aware colored text presentation without making either renderer the logic source.
