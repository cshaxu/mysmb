# Product UX

## Native Game

The graphical product launches directly into the game. It has no emulator monitor, runtime ROM picker, or required configuration menu.

## Text Presentation

The text product uses an 80×25 colored character scene. It draws known game objects and their states using filled cells, outlines, and glyph detail; it is not a luminance-to-ASCII filter.

## Host Resources

Windows supplies a normal native graphical/full-screen experience. The future 16-bit target supplies VGA full-screen graphics. Input, timing, sound, pause, and exit behavior are platform-adapter responsibilities.
